# Z-City для Roblox — песочница

Режим в духе [Z-City](https://github.com/uzelezz123/Z-City) (аддон для Garry's Mod на базе Homigrad/Homicide), перенесённый в Roblox.
Сейчас готова **песочница** для проверки механик. Режим Homicide будет следующим шагом.

## Что есть в песочнице

- **Организм вместо HP** (по мотивам `lua/homigrad/organism` из Z-City):
  - кровь 5000 мл, раны и кровотечение, артерии (не сворачиваются сами), внутреннее кровотечение;
  - пульс, кислород, повреждение мозга. Смерть наступает так же, как в Z-City: кровопотеря или остановка сердца → кислород падает → мозг повреждается → смерть;
  - боль, обезболивающее, адреналин, потеря сознания (кровь < 2400 мл, сильная боль, нокаут);
  - попадания по частям тела: голова (мозг), грудь (сердце, лёгкие, позвоночник), живот (печень, позвоночник), руки и ноги (артерии, переломы);
  - переломы ног замедляют и запрещают прыжки, переломы рук и боль увеличивают разброс;
  - урон от падения (переломы ног, позвоночник).
- **Регдолл** (аналог `fake` из Z-City): при потере сознания, переломе позвоночника, двух сломанных ногах или большой кровопотере тело падает. Встаёт само, когда состояние позволяет. Можно упасть и встать вручную (G).
- **Оружие:** пистолет, автомат, дробовик, нож, бита. Попадания считаются на сервере.
- **Медицина:** бинт (закрывает рану), жгут (останавливает артериальное кровотечение на руке или ноге), обезболивающее, адреналин.
- **Песочница:** меню (Q) для выдачи предметов, манекены для тестов, лечение себя. Карта: пол, укрытия и башни 12/20/35/60 studs с лестницами для проверки падений.
- **HUD:** кровь, пульс, кислород, боль, кровотечение, переломы. При наведении на манекен видно его состояние. При потере сознания экран темнеет.

## Управление

| Клавиша | Действие |
| :--- | :--- |
| ЛКМ | атака / применить предмет |
| R | перезарядка |
| G | упасть / встать |
| Q | меню песочницы |

## Как загрузить в Roblox Studio

### Вариант 1: Rojo (рекомендуется)

1. Установите [Rokit](https://github.com/rojo-rbx/rokit) и выполните в папке проекта `rokit install` (поставит Rojo из `rokit.toml`).
   Или скачайте Rojo 7.4.4 со страницы [релизов Rojo](https://github.com/rojo-rbx/rojo/releases).
2. Установите плагин Rojo для Studio: `rojo plugin install`.
3. Запустите в папке проекта `rojo serve`.
4. Откройте в Studio пустое место (Baseplate), во вкладке **Plugins → Rojo** нажмите **Connect**.
5. Нажмите **Play**.

Можно также собрать файл места: `rojo build -o ZCitySandbox.rbxlx` и открыть его в Studio.

### Вариант 2: вручную

Создайте в Studio скрипты и вставьте код из файлов:

| Файл | Куда в Studio | Тип |
| :--- | :--- | :--- |
| `src/shared/Config.luau` | ReplicatedStorage → Folder `Shared` → `Config` | ModuleScript |
| `src/shared/BodyMap.luau` | ReplicatedStorage → Folder `Shared` → `BodyMap` | ModuleScript |
| `src/server/Main.server.luau` | ServerScriptService → Folder `Server` → `Main` | Script |
| `src/server/Organism.luau` | ServerScriptService → Folder `Server` → `Organism` | ModuleScript |
| `src/server/Ragdoll.luau` | ServerScriptService → Folder `Server` → `Ragdoll` | ModuleScript |
| `src/server/Weapons.luau` | ServerScriptService → Folder `Server` → `Weapons` | ModuleScript |
| `src/client/Main.client.luau` | StarterPlayer → StarterPlayerScripts → `Main` | LocalScript |
| `src/character/Health.server.luau` | StarterPlayer → StarterCharacterScripts → `Health` | Script (пустой, отключает регенерацию) |

## Как проверить

1. **Play**, откройте меню (Q), создайте манекен.
2. Стреляйте из пистолета в разные части тела и наводите курсор на манекен: видно кровь, пульс и последнее ранение.
3. Выстрел в голову обычно убивает сразу; в грудь может остановить сердце (смерть примерно через 40 секунд); в ногу может задеть артерию или сломать кость.
4. Ранить себя можно падением с башни 35 или 60. Проверьте бинт, жгут и обезболивающее на себе.

## Настройка

Все числа (кровь, пороги сознания, урон и скорострельность оружия) лежат в `src/shared/Config.luau`.
Ограничения суставов регдолла — в начале `src/server/Ragdoll.luau`.
